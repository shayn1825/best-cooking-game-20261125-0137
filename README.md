**Lapar Kilat** — a timed Indonesian warung cooking game. Customers order from the board, you run the kitchen: grab ingredients from the counter, fry in the wok, grill satay, chop on the board, build plates at the assembly counter, and serve at the window before patience runs out. Rush hour hits in the last 45 seconds — more orders, shorter timers, bigger combos. One shift, 2.5 minutes, 3 hearts.

Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — or serve game/ with any static server
```

Play with WASD / arrow keys + E, or click the floor to walk and click stations to use them. Q tosses what's in hand, P pauses, M mutes, R restarts.
